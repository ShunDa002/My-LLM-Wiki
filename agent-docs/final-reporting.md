# Final Reporting Requirements

## Scope

Load this document after every approved write, including a partial or failed write.

## Required report fields

Report:

- Completed operation.
- Every source file read.
- Every file created.
- Every file modified.
- Every planned file not changed.
- Any file skipped because it was outside scope.
- Validation commands or checks actually performed.
- Validation results and failures.
- Remaining uncertainty and open questions.
- Contradictions or decisions requiring human review.
- Whether the operation partially completed.
- Confirmation that `raw/` was not modified.
- Confirmation that `dev/` was not modified.
- Confirmation that no Git write operation was performed.
- A recommendation to inspect `git status` and `git diff`.

Do not describe generated content as human-reviewed. The report is not approval of the resulting knowledge.

Use `templates/final-report.md` when helpful.
