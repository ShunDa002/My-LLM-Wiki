# Essentials of Linux Commands and Vim Operations

以下是视频中讲解到的所有 Linux 及相关工具的命令笔记，已为您进行分类整理，方便阅读和复习：

## 1. 虚拟机工具命令 (Multipass)

*   **multipass launch**：创建并安装一个 Ubuntu 系统虚拟机。
*   **multipass list**：查看当前已安装的虚拟机列表。
*   **multipass <虚拟机名称>**：进入指定的虚拟机环境中。

## 2. Vi / Vim 文本编辑器

Vi/Vim 是 Linux 中最常用的命令行文本编辑器。

### 打开/创建文件
*   **vi <文件名>** 或 **vim <文件名>**：如果文件不存在则会新建一个文件。

### 模式切换
*   进入 Vim 后默认为“**命令模式**”。
*   按下特定的键进入“**插入模式**”。
*   按 **ESC** 键退出插入模式并回到命令模式。
*   按 **:** 键进入“**底行模式**”。

### 插入模式快捷键
*   **i / I**：在光标当前位置前面插入 / 在当前行的行首插入。
*   **a / A**：在光标当前位置后面插入 / 在当前行的行尾插入。
*   **o / O**：在当前行的下一行插入 / 在当前行的上一行插入。

### 命令模式快捷键（光标移动与编辑）
*   **光标移动**：h (左)、j (下)、k (上)、l (右)。方向键同样适用。
*   **行内跳转**：^ (跳转到当前行的行首)，$ (跳转到当前行的行尾)。
*   **翻页**：
    *   **Ctrl+F**：向后翻整页
    *   **Ctrl+B**：向前翻整页
    *   **Ctrl+D**：向下翻半页
    *   **Ctrl+U**：向上翻半页
*   **指定行跳转**：
    *   **G**：跳转到最后一行
    *   **gg**：跳转到第一行
    *   **[行号]G**：跳转到指定行（如 100G）
*   **复制/粘贴/删除**：
    *   **yy**：复制当前行
    *   **p**：粘贴到下一行
    *   **dd**：删除当前行
    *   *注：在这些命令前加数字可以多次执行（例如 2yy 复制两行，3p 粘贴三次）。*
*   **撤销**：**u** (撤销刚才的修改，相当于 Ctrl+Z)。

### 查找与替换（底行模式）
*   **查找**：**/查找内容** (向下查找)，**?查找内容** (向上查找)。
    *   按小写 **n** 继续向原方向查找下一个。
    *   按大写 **N** 反向查找下一个。
    *   在查找内容后加 **\c** 可忽略大小写（如 `/hello\c`）。
*   **替换**：格式为 `:[范围]s/旧内容/新内容/[g]`。
    *   `:s/hello/word/`：替换当前行第一个。
    *   `:s/hello/word/g`：全局替换当前行所有匹配项。
    *   `:1,5s/...`：替换1-5行。
    *   `:%s/...`：替换整个文件所有内容。

### 保存退出及其他（底行模式）
*   **:q**：退出。
*   **:wq**：保存并退出。
*   **:set number** (或 **:set nu**)：显示行号。
*   **:set nonumber**：关闭行号显示。
*   **:行号**：直接跳转到指定行（如 :50 跳转到第50行）。

## 3. 文件与目录基础操作命令

*   **pwd**：显示当前所在目录的完整绝对路径。
*   **cd**：切换目录。
    *   **cd /**：切换到根目录。
    *   **cd .**：当前目录。
    *   **cd ..**：切换到上一级目录。
    *   **cd ../..**：切换到上一级的上一级目录。
    *   **cd ~**：切换到当前用户的家目录。
    *   **cd -**：切换到上一次所在的目录。
*   **ls**：列出目录下的内容。
    *   **-l**：显示文件详细信息（权限、所有者、大小、时间等）。
    *   **-a**：显示所有文件，包含以 `.` 开头的隐藏文件。
    *   **-h**：以人类可读的方式显示文件大小。
    *   **-t**：按修改时间排序。
    *   **-r**：逆序显示。
    *   **-i**：查看文件的 inode 节点号。
    *   *注：参数可以组合使用，如 `ls -ltr`。*
*   **mkdir**：创建目录。使用 **-p** 参数可递归创建多级嵌套目录（如 `mkdir -p folder1/folder2`）。
*   **cp**：复制文件。使用 **-r** 参数可以递归复制整个目录及其包含的所有内容。
*   **mv**：移动文件，也可用于重命名文件。
*   **rm**：删除文件。
    *   若要删除空目录，直接输入目录名即可。
    *   若目录非空，必须使用 **-r** 参数递归删除（如 `rm -r folder_name`），此操作极度危险，不可逆。
*   **du**：查看文件或目录的大小。可加 **-h** 参数使大小更易读。
*   **tree**：（非系统自带，需安装）以直观的树状图形式显示目录结构。

## 4. 文件创建、查看与输出

*   **touch**：当文件不存在时创建一个空文件；若文件已存在，则更新该文件的修改时间。
*   **echo**：在终端输出文本。常结合重定向符号 **>** 将输出的内容写入到文件中（如 `echo Hello Linux > 2.txt`）。
*   **cat**：查看并打印出文件的全部内容。

## 5. 软硬链接管理

*   **ln**：创建硬链接文件。硬链接和原文件共享相同的 inode 节点，修改其中一个，另一个同步变化；即使原文件被删除，硬链接依然可以正常访问。
*   **ln -s**：创建软链接（符号链接），类似于 Windows 的快捷方式。不存储文件内容，只存储目标路径。如果删除了目标原文件，软链接将会失效。

## 6. 文件权限管理 (chmod)

文件权限分三组（所有者、所属组、其他用户），每组拥有读 (r，值为4)、写 (w，值为2)、执行 (x，值为1) 的权限。

*   **chmod +<权限> / chmod -<权限>**：给所有用户添加或删除权限（如 `chmod +x` 增加可执行权限）。
*   **chmod u/g/o +/- <权限>**：给特定用户组添加/删除权限。
    *   **u** 代表所有者 (user)
    *   **g** 代表所属组 (group)
    *   **o** 代表其他用户 (other)
*   **chmod <数字组合>**：使用数字相加的模式直接修改权限（例如 `chmod 777` 表示最高权限，`chmod 644` 表示默认权限）。
